# SuperApp

A decentralized, peer-to-peer super app with a node on every device, built for private communication, user-owned identities, and a community-run network.

## Download the Android test APK

**[Download SuperApp for Android — build 4](https://github.com/superapp26/superapp/releases/download/v0.1.0%2B4/superapp-0.1.0-arm64.apk)**

[Release notes and checksums](https://github.com/superapp26/superapp/releases/tag/v0.1.0%2B4) · [All releases](https://github.com/superapp26/superapp/releases)

Requires an ARM64 phone running Android 8 or later. On a release page, expand **Assets** and select the `.apk` file; GitHub's generated source archives are not the Android installer.

This is an early test prerelease, not a production-qualified app. Build 4 includes the embedded node, direct messaging, signed-membership groups, foreground voice/video calls, local privacy controls, encrypted backup/restore, and participant-operated offline mailboxes. Use the same build on all test phones.

The equity ledger and 22% founder allocation are not active in this APK. Founder credentials and distributed equity integration are separate work in progress. Do not treat a local node identity or this release as proof that shares have been issued.

Two-phone, cross-network, Android background, and upgrade qualification are incomplete. Use non-sensitive test data. Upgrade in place; do not uninstall or clear app data to troubleshoot installation because that can erase the local identity and history.

The complete app source will be uploaded separately. This repository's initial files and automatically generated source archives are not yet the source corresponding to the APK.
